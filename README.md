# Adaptive Cozy Planner

A polished offline-first V1 mobile planner built with Expo, React Native, TypeScript, and Expo Router. It adapts a day around the user's actual energy and time rather than punishing changed plans.

## Run locally

```bash
npm install
npm start
```

Then scan the QR code with Expo Go, or press `i`/`a` for an installed iOS Simulator or Android emulator.

## Included in V1

- Four native tab screens: Today, Calendar, Goals, and My Space
- Editable daily check-in, mock planning/replanning, partial progress, and procrastination support
- Global natural-language planning sheet with mocked parsing
- Persistent tasks, goals, coins, life progress, seasons, furniture layout, and rewards
- Cozy studio apartment with draggable owned items and four seasonal atmospheres

The AI parser and planner intentionally use local deterministic mock logic. Undo/redo controls are visual placeholders in V1; item movement and saved local persistence work.
